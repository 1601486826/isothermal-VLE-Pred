# isothermal-VLE-Pred
Developed a comprehensive web platform using Streamlit to predict isothermal Vapor-Liquid Equilibrium (VLE) behavior, specifically generating p-x-y (Pressure-Composition) phase diagrams.

Implemented an ensemble learning strategy, benchmarking and comparing predictions from multiple algorithms (Neural Networks, CatBoost, LightGBM) to ensure high accuracy and robustness.

Integrated RDKit for real-time 2D molecular structure visualization, allowing users to instantly verify chemical inputs (SMILES) alongside system parameters.

Tech Stack: Python, Streamlit, Scikit-learn, CatBoost, LightGBM, RDKit, PyTorch.

Web: https://isothermal-vle-pred.streamlit.app/
